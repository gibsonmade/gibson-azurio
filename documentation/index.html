Getting Started

Welcome to Gibsooon Next.js Project Documentation. This guide is tailored to your current project: Gibsooon-nextjs.

Built with modern technologies Next.js + TypeScript + CSS, this high-quality and well-organized template is designed for AI, technology, SaaS, and digital agency websites. It includes a wide range of custom sections, multiple home pages, inner pages, and extensive design flexibility.

This is a complete and highly customizable Next.js template to help you build professional website layouts quickly and efficiently.

Requirements

Before installing the template, make sure your environment is ready. You should have Node.js and Yarn installed on your computer.

Next.js Installation

Follow the steps below to run the project locally and prepare it for deployment:

  1. Run on localhost -
    1. Open your terminal or command prompt
    2. Run yarn install
    3. Run yarn dev (starts the development server at http://localhost:3000)
  2. Deploying to Netlify - https://www.youtube.com/watch?v=Bj_r9AJpv0I&pp=ygUVbmV4dGpzIGRlcGxveSBuZXRsaWZ5


  1. Create and run a production build locally -
    1. Open your terminal or command prompt
    2. Run yarn build (creates an optimized production build)
    3. Run yarn start (starts the production server at http://localhost:3000)
  2. Deploying to Vercel - https://youtu.be/AiiGjB2AxqA


Other Scripts
  1. Open your terminal or command prompt
  2. Run yarn format to format the project with Prettier
  3. Run yarn lint to check ESLint rules, or yarn lint:fix to apply auto-fixable ESLint issues
